# Discovery

Documentos de discovery/PRD produzidos pelo playbook `.cursor/playbooks/playbook-discovery.md`.

## Convenção de nomes

```
docs/discovery/YYYY-MM-DD-<tema>.md
```

Exemplo: `docs/discovery/2026-08-30-export-markdown-v2.md`

## Fluxo

```text
playbook-discovery → (aprovação) → playbook-feature → implementação
```

Nesta fase **não** se altera código de produto — apenas planejamento acionável com RFs, gaps evidenciados e plano de testes.
